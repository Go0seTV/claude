# Mes outils

- **[RangeMusique](RangeMusique/LISEZMOI.md)** : identifie (empreinte audio), tague et range
  une bibliothèque musicale par `Artiste\Album`, sans doublons, en supprimant les dossiers
  vides et intermédiaires.
- **[Livre de cuisine](LivreCuisine/LISEZMOI.md)** : importe les recettes enregistrées dans
  une collection Instagram (légende, vidéo transcrite, photos) et les range dans un livre de
  cuisine sur le PC, avec recherche, catégories, favoris, notes et impression en PDF.
